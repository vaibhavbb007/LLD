# LLD Practice

Hands-on practice for **Low-Level Design (LLD)** and **Object-Oriented Design (OOD)** using Java.

* Object modeling
* Responsibility assignment
* Encapsulation & SOLID
* Design patterns
* Extensibility
* Clean, testable code
* Interview problem-solving speed

## Approach

For each problem:

```text
Requirements
→ Design
→ Implementation
→ Test
→ Review
→ Refactor
```
